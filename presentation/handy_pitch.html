Cloud Dependency

Existing apps require an internet connection, introducing latency, privacy risk, and failure in low-connectivity areas.

🔤

Alphabet-Only Recognition

Most mobile apps only recognize fingerspelled letters — not full signs — making real conversation painfully slow.

💸

🔒

Privacy Concerns

HANDY
Our Solution
On-device ASL understanding,
no internet required.

Handy is a real-time ASL communication assistant that runs entirely on a standard Android phone. It combines gesture recognition with an on-device large language model to translate signed gestures into natural English — and helps hearing people respond back in sign.

No cloud. No API key. No interpreter. Just your phone.

Works fully offline — zero internet dependency
Real-time gesture recognition at ~30 fps
On-device Gemma 3n LLM for natural language
Intent detection + 3 contextual reply options
Auto-translates on signing pause (2 seconds)
Suggests signs for the hearing person to make back

Architecture
How It Works
📷

Camera Input

Live camera feed captures hand position at ~30 fps using the phone's front camera.

→
🖐️

Hand Landmark Detection

MediaPipe detects 21 hand keypoints per frame and classifies the gesture with a confidence score.

→
📝

Session Building

Stable gestures are committed to a token sequence. A stability filter prevents noise from single frames.

→
✨

On-Device LLM

Gemma 3n (2B, INT4) translates tokens into natural English, detects intent, and generates 3 reply options.

→
💬

Conversation

Hearing person selects a reply chip and speaks it aloud via TTS. Context is preserved across turns.

HANDY
Key Features
Built for real conversations.
⏱️

Auto-Translate on Pause

Signing stops for 2 seconds → translation fires automatically. No button press needed mid-conversation.

🏷️

Intent Detection Badge

Gemma classifies the emotional intent alongside translation — Question, Greeting, Request, Emotion, and more.

💬

Three Reply Chips

Gemma generates Formal, Casual, and Empathetic reply options. Tap one → Copy or Speak it aloud via TTS.

🤟

Gesture Suggestion

Hearing person types a phrase → Gemma suggests which hand signs to make back. Full two-way communication.

🧠

Conversation Context

Previous exchanges are stored and fed back into prompts so Gemma understands the full conversational thread.

🔒

100% Offline & Private

Everything runs on-device. No data leaves the phone. Works in hospitals, schools, remote areas — anywhere.

HANDY
Technology
Built on proven on-device AI.
Language Model

Gemma 3n E2B INT4

Google's 2B parameter edge LLM, quantized to 4-bit integers via LiteRT. ~2.9 GB on device. Zero cloud calls.

ML Runtime

MediaPipe Tasks GenAI

Google's on-device inference runtime (v0.10.24). Handles model loading, tokenization, and streaming generation.

Gesture Recognition

MediaPipe Tasks Vision

Hand landmark detection at ~30 fps. Tracks 21 keypoints, classifies gesture with confidence score in real time.

UI Framework

Jetpack Compose

Modern declarative Android UI with Kotlin coroutines, StateFlow, and AndroidViewModel for reactive state management.

Platform

Android (Kotlin)

CameraX for live feed, TextToSpeech for audio output, CPU-based inference for broad device compatibility.

Two-hand & body gesture support — extend MediaPipe pipeline to full-body pose for richer ASL coverage.
